## 2. 新增实现

### 2.1 `src/go2_rescue/public_task.py`

- `PublicTask.load(task_dir, catalog)`：解析 manifest/sensors/scene，逐文件校验摘要（缺失/不匹配即抛错）；用 manifest SHA-256 校验 catalog 条目；拒绝路径逃逸；
- `body_from_camera()`：由 `sensors.camera.position_m` 与 `xyaxes` 计算，保持旧配置的相机光学轴约定（x=xyaxes[0]、y=-xyaxes[1]、z=x×y）；
- `camera_matrix()`：由 `fovy_deg` 与 320×240 生成 `fx=fy=207.846`；
- `config()`：把相机尺寸/内参/外参、LiDAR 安装点、96° 垂直视场、中心 0°、0.01 m 噪声、1% 丢点、0.05–12 m 量程、`-0.22 m` 高度门限写进 `Config`；设置 `lidar_contract_order=True`；
- `build_observation()`：按 agent 合同拼 189 维：角速度×0.25、投影重力、command、关节位置差、关节速度×0.05、上一动作、144 维 LiDAR；形状校验；
- `sensor_meta()`：8 维 age/valid 顺序；`[3]` 使用**高度筛选/归约前的原始有效射线数 / 648**，72 方位有效比另存为诊断字段。

### 2.2 传感器参数化（`config.py`、`mujoco_sim.py`）

- 新增 `lidar_mount`、`lidar_noise_std`、`lidar_dropout`、`lidar_contract_order`；
- `SimSensors` 使用配置安装点；`lidar_contract_order=True` 时按合同顺序：量程裁剪 → 1% 丢点 → 1 cm 噪声 → 重力高度过滤 → 每方位最近回波；旧 profile 保留原顺序；
- 相机 fovy 由 `camera_matrix` 推导，不再硬编码 60°；
- `mapping.GridMap` 的证据射线起点改用 `config.lidar_mount`，不再硬编码 0.10 m；
- `RangeOnlyEvidence` 增加可选 `origin_body` 参数（默认仍 0.10 m，旧调用不变）。

### 2.3 `scripts/public_contract_smoke.py`

对参考任务执行六步合同冒烟（不跑 Agent 模型）：

- 第 0、5 步采新 RGB/LiDAR，第 1–4 步复用缓存；
- 生成 obs[6,189]、rgb[6,3,64,64]、state[6,32]、sensor_meta[6,8]、LiDAR ranges/masks[6,72]；
- 校验摘要、catalog 摘要、单/双 batch 头部、state 全零重置、按键顺序、CPU/NumPy、有限值；`sensor_meta[3]` 等于原始有效射线比例。
