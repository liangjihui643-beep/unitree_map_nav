按最终指令停止维护两张地图：运行时只保留 `GridMap`；`ContractMap` 退为实验记录，不再作为可选运行时地图。

## 1. GridMap 改动

- 端点相对高度不再回退到 `ground_height`：`floor_at_hit` 缺失时，用 **2.5 m 内最近的实测/插值/足迹地面**（`_local_ground`）作为当地参考；仍无当地地面则把端点存入 `pending_endpoints`。
- 每帧结束后 `_reclassify_pending()` 用当前当地地面重分类待定端点；连续坡面接上后，原先被误判为障碍的端点可撤销/降为结构。
- 新增 `structure_votes`、`overhead_votes` 独立层；`save()` 增加 `structure_votes`、`overhead_votes`、`pending_endpoint_count`。
- 自由更新与端点分类分开：端点缺当地地面时不再用脚底高度替代，也不清自由；待定端点不写自由。
- 未改动 `traversable()` 的发布接口；下游仍读同一张 `GridMap`。
- 144 维合同输入尚未在 GridMap 内形成可用自由区；本轮按指令把交付范围保持在现有 XYZ 实时链路。

## 2. 同 154 帧对照（完整 GridMap 基线 vs 合入后）

基线为 `BaselineGridMap`：只恢复旧的脚底高度回退，其余同一代码；两图使用同一批 `selected_points`、同一估计位姿。

| 指标 | 基线（旧回退） | 合入后 |
|---|---:|---:|
| 占据格 | 1037 | 1030 |
| 坡面假占据 | 26 | **17** |
| 平地假占据 | 23 | 27 |
| 机身高度真障碍确认 | 357/893 | **362/893** |
| 错误自由 | 848 | 849 |
| 自由格 | 10479 | 8040 |
| 待定端点 | 0 | 314 |

结论：统一自由/占据记账后，坡面假占据 26→17、真障碍 357→362，错误自由 848→849；平地假占据 23→27，自由格 10479→8040。按本轮“取消自由格硬目标”的口径，坡面和真墙两项改善；入口/平地连通性尚未在同一 `traversable()` 上复核，不能定版。

原因：去掉脚底回退后，缺少当地地面的远端射线不再清自由；一部分正常自由被保守地留在未知。当前只做了“不伪造地面”，没有完成“连续坡面局部补全后重算自由”。
