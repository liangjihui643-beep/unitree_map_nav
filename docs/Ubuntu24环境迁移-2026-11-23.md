# Ubuntu 24.04 环境迁移与验证（2026-11-23）

## 结果

- 新增 WSL 发行版 `Ubuntu-24.04`（24.04.3 LTS），安装**原生 Python 3.12.3**；原 `Ubuntu-20.04` 保留，但默认 distro 已切到 24.04。
- 代码逻辑未修改；仓库仍只有一套 `GridMap`。
- 24.04 上使用 20.04 的 Mesa 21 EGL/GLX/DRI 组合（复制到 `/opt/gl-libs`），配合：

```bash
LD_LIBRARY_PATH=/opt/gl-libs:/usr/lib/wsl/lib
LIBGL_DRIVERS_PATH=/opt/gl-libs/dri
MUJOCO_GL=egl
```

离屏渲染实际走 **D3D12 (NVIDIA RTX 4060)**，不再退回 llvmpipe。

## 启动方式

两个 Windows 启动脚本已改为：

- 默认 `GO2_WSL_DISTRO=Ubuntu-24.04`；
- 向 WSL 传入上述 `LD_LIBRARY_PATH`、`LIBGL_DRIVERS_PATH`、`MUJOCO_GL=egl`。

直接手动运行时也应显式设置这三个变量；裸 shell 不会自动加载 `/opt/gl-libs`。

## 说明

- Mesa 25 原生 EGL 走 llvmpipe；Mesa 24/21 直接放系统路径会报 `PLATFORM_DEVICE`。当前方案是把 20.04 的 Mesa 21 栈放 `/opt/gl-libs`，由启动脚本注入，不改系统默认库，也不改代码。
- 全量测试剩余 3 项与 20.04 一致，属于既有问题；24.04 已没有新增的渲染/相机失败。
