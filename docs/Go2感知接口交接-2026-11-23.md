# Go2 感知接口交接（2026-11-23）

本文对应训练包 1.3.1 与 Go2 接口文档 1.0.05。项目内使用一个 GridMap。交接分成已有 XYZ 感知链路的输入与三类输出，以及公开任务的传感器输入适配。

## 1. 本地实时链路如何接

进程内沿用 `go2_rescue.types.Frame`。输入时间戳使用同一来源的单调秒，点云是机身 FLU 下的 N×3 米制 XYZ，四元数顺序 wxyz，速度是机身观测，图像使用 OpenCV BGR，支撑脚点可选。调用现有 Autonomy 和感知循环时，地图和位置使用起点相对坐标 `map_start`。进程外传感器桥可继续使用已有 `go2-rescue live --endpoint ...` 和 `go2-rescue-frame/1`，其时间戳使用主机 monotonic 时钟。

MuJoCo 的 `--perception-demo` 每约 0.5 仿真秒以及结束时原子覆盖一次 `<run>/perception_snapshot.json`。队友可以在进程外轮询这个文件。每次得到的是同一时间基准下的一份完整快照，使用新的内容整体替换缓存。不要把旧帧中的格子和目标叠加到新快照上。一个运行目录只对应一个会话，重启后从新目录读取。

| 字段 | 含义 |
|---|---|
| `schema`, `frame`, `time_s` | 版本 `go2-perception-snapshot/1`，`map_start`，仿真或输入时钟域的秒。不能与墙钟直接比较 |
| `lidar_input` | `body_flu_xyz`，表明以下地图来自 XYZ 链路 |
| `map.origin_xy_m`, `resolution_m`, `shape` | 栅格几何，索引为 `[i,j]=[x方向格号,y方向格号]`，格心为 `origin+(ij+0.5)*resolution` |
| `map.occupied_ij`, `ray_free_ij`, `traversable_ij` | 占据、射线自由及规划可用三种掩膜。规划只用 `traversable_ij`，其余格不能直接作为通路 |
| `terrain` | 原有 `go2-terrain-layer/1` 整体快照。区域修订模式读取 `single_view_rubble.cells`，否则读取 `cells`。高度字段允许为空；避让消费端使用各自附带的几何信息 |
| `confirmed_target_xy_m` | 当前地图坐标下已确认目标列表。该列表是运行期标记，检测暂时消失不代表该标记应立即撤回 |
| `target_observation` | 最近一次相机测量的时间、原图宽高及像素圆候选。每项有置信度、测距来源和从基座到候选的水平距离（没有可靠位置时为 null）。收到重复相机时间戳时不要重复使用测量；导航应使用确认目标列表 |

最小读取入口：

```python
import json
from pathlib import Path

snapshot = json.loads(Path("output/<run>/perception_snapshot.json").read_text(encoding="utf-8"))
assert snapshot["schema"] == "go2-perception-snapshot/1"
traversable = {tuple(ij) for ij in snapshot["map"]["traversable_ij"]}
terrain = snapshot["terrain"] or {}
avoid = (terrain.get("single_view_rubble") or terrain).get("cells", [])
targets = snapshot["confirmed_target_xy_m"]
```

原来的 `map.npz`、`terrain_layer.json` 和 `target_tracks.jsonl` 仍可供历史工具使用。上述实时统一输出接在 MuJoCo 感知演示入口，实机桥发布请复用同一序列化函数，尚未做实机联调。

## 2. 公开任务输入如何接

使用训练包的同一任务目录载入 `PublicTask`，传入目录上一级的 `catalog.json` 进行摘要校验。使用 `PublicSensorStream(task.config())` 解码单控制步的 `obs[189]`、`rgb[3,64,64]` 与 `sensor_meta[8]`，时间戳为该控制步的仿真秒。每个回合新建对象或调用 `reset()`。

```python
from go2_rescue.public_task import PublicTask
from go2_rescue.perception_io import PublicSensorStream, public_range_evidence

task = PublicTask.load(task_dir, catalog)
stream = PublicSensorStream(task.config())
# grid is the consumer's GridMap built with task.config()
evidence = public_range_evidence(grid)
# From here, repeat for each control step:
sample = stream.decode(t_sim, obs, rgb, sensor_meta)
if sample.lidar_obs is not None and sample.imu_valid:
    # grid must use this task's config; pose is an external estimated map pose
    evidence.update(grid, sample.lidar_obs, sample.roll_pitch_wxyz, pose,
                    grid.c.min_range, grid.c.max_range)
if sample.image_bgr is not None:
    consume_image(sample.image_bgr, sample.rgb_time_s, stream.camera_matrix_64)
```

Agent 50 Hz 控制，传感器 10 Hz 更新，缓存步的 `lidar_obs` 和 `image_bgr` 返回 None，避免重复累计。输出的滚转俯仰四元数由投影重力得到，其 yaw 置零。全局位姿、偏航和线速度需另估。掩码为 0 的雷达方位保持无效，不能作为 12 m 自由射线。该适配使用任务外参，不生成虚假的 XYZ；范围假设诊断也不等于可交给规划的全地图。

## 3. 范围

交接版覆盖本地 XYZ 感知三类输出及公开任务的非 ONNX 输入适配。公开 144 维输入还不能独立替代 XYZ 地图或已有融合链路。模型训练、推理合同、模型导出与赛站验收留在对应工作项。

实测快照示例为项目内 `output/perception-interface-smoke-20261123/perception_snapshot.json`。复现时在项目目录运行 `MUJOCO_GL=egl .venv/bin/python -B -m go2_rescue.cli mujoco --perception-demo --control perception-walk --seconds 1.5 --output <新目录>`。该冒烟验证发布链路，起点无可确认目标时目标列表允许为空。
